## 🚀 Featured Projects

### 📄 [ResumeIQ – AI Resume Analyzer Platform](https://github.com/abhi-7755)
> An intelligent SaaS platform designed for parsing resumes, calculating ATS compatibility scores, and offering actionable feedback.

- 🤖 **AI Analysis:** Integrated Ollama-based LLMs for automated resume evaluation, job description matching, interview prep, and customized cover letter generation.
- 🔒 **Security & Auth:** Configured JWT authentication, secure document uploads, and RESTful APIs with PostgreSQL persistence managed via Prisma ORM.
- 📊 **Analytics Dashboard:** Built a modern SaaS interface providing real-time ATS score metrics, submission history, and step-by-step optimization recommendations.

### 📊 [Quantara – AI Business Analytics Platform](https://github.com/abhi-7755)
> A full-stack data analytics engine empowering organizations to gain insights from structured data effortlessly.

- 📈 **Automated Profiling:** Upload CSV/Excel datasets for automated data quality checks, statistical profiling, and anomaly detection.
- 💬 **AI Copilot:** Embedded an interactive AI copilot for querying complex business datasets using natural language questions.
- 🔐 **Multi-Tenancy Architecture:** Built with secure multi-company data isolation, utilizing Next.js, Python FastAPI, Ollama, and Supabase.
